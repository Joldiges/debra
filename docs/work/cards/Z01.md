# Z01 — full original Zero W support: dependency reconnaissance

Read Z01, the brief's ARMv6 goal, and legacy findings. Inspect public upstream
sources and named historical leads; do not run old build scripts or binaries,
download/install wheels, build containers, or contact a Pi.

## Bounded questions

Trace voice/LVA, wake runtime/model libraries, SendSpin receiver, core audio
libraries, Python, and OS/kernel requirements. Resolve inspected upstream
versions and native dependencies; distinguish ARMv6/Raspbian armhf from ARMv7
and AArch64. Historical wheel names are leads, not execution evidence.

## Acceptance

Return a dependency/instruction-set/ABI matrix with direct primary references,
available artifacts, missing/unclear artifacts, and ranked blockers. Propose
bounded isolated build/runtime experiments with expected evidence. Investigate
offload options without silently downgrading the full-support goal. Mark runtime,
performance, and combined-operation tests `not-run`; Pi 5 success proves none.
