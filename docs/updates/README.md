# Updates

Short, dated progress logs meant to be read by James without scrolling chat.

- One file per day: `docs/updates/YYYY-MM-DD.md`.
- **One entry per task or work segment**, written as that segment finishes — not
  a periodic heartbeat. Entries are appended in the order work happened, newest
  last, and are not rewritten later; a correction is a new entry that cites the
  earlier one.
- Each entry says what changed, what was actually verified, what is still
  unproven, and what happens next.
- These are working notes, not approvals. A claim here has the same evidence
  status as anywhere else in `docs/` until a review adopts it.
- `docs/notes/` remains the place for dated findings and corrections;
  `docs/updates/` is the chronological activity log.
- They are tracked on purpose: they are the honest record of what was done and
  what was not. If they should be private instead, move the folder under
  `.local/` and add it to `.gitignore` — that is a one-line change, not a
  rewrite.
