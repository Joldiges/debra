Change the Wi-Fi networkPlanned

Join a different Wi-Fi network from this page; no Wi-Fi-change operation is available here yet (roadmap N02, WEB02). The onboarding service can raise its own access point and join a network, but it is not connected to this page and has never run on a device.

Restart speech or musicPlanned

Restart speech or music from this page; no service-restart operation is available here yet (roadmap C02, WEB08). Nothing on the device can start, stop or restart a service.

Keep a known-good copyPlanned

Keep and restore a working setup; this page has no snapshot or restore operation yet (roadmap B01, B02). A first baseline can be captured and inspected; nothing restores from one, so recovery in that direction is unproven.

Maintenance menuPlanned

Use a text maintenance menu when this page cannot be reached; that menu does not exist yet (roadmap C04).

Send a question through this page and hear a reply on the device; this page has no connection to the voice assistant yet (roadmap V01, V03).
