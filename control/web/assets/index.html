About this output

A level links all output channels. Mute is separate. Percent is a native control setting, not a loudness or safety measurement. This page controls this device’s own output; whether speech and music both use it is not something this page checks.

Health & resources

CPU-core voltagePlanned

A collector will show CPU-core voltage; this reading is not implemented yet. The 5 V supply above is a different measurement.

Readings show what the device reported when it last answered. It does not report when it measured them, so reading age is unknown; showing observation times is Planned.

Heaviest processes

CPU is a share of one core, so a program using several cores can report more than 100%. Each figure is the device’s own counters between two reads, and the first read has no earlier counters, so it leaves CPU blank rather than showing zero.

Per-core CPU
Swap & compression

Swap I/O is system-wide pages/second—not a zram/zswap benchmark. Counters need two samples. zswap pool statistics require a future permitted collector; no root access is requested.

What this device reports

The EEPROM product string can name a board family only: nothing this page reads establishes an exact model or revision, and an alternative that is not a board — the jack or USB output — is not something it can name.

Audio hardware

Installing writes one overlay line into the boot configuration, keeps a timestamped copy of the file beside it, and takes effect after a restart. It does not restart anything by itself.

Installing needs one setup step on the device first: run sudo python3 -B control/setup/hat_install.py --enroll from the Debra tree, once, and answer the password prompt. It installs a small root helper behind a socket that only this page’s account can open, and starts it. No passwordless sudo rule is involved.
