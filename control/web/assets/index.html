Device tasks

The jobs a person will come to this page for. Every row is Planned: nothing here can be used, and none of it changes the device. They are listed so the intended shape of the appliance is visible and can be tested against.

Change the Wi-Fi networkPlanned

Join a different network from this page instead of a terminal. The onboarding service can raise its own access point and join a network, but it is not connected to this page and has never run on a device (roadmap N02, WEB02).

Restart speech or musicPlanned

Restart a service without opening a terminal. Nothing on the device can start, stop or restart a service yet (roadmap C02, WEB08).

Keep a known-good copyPlanned

Take a snapshot of the working setup and go back to it. A first baseline can be captured and inspected; nothing restores from one, so recovery in that direction is unproven (roadmap B01, B02).

Maintenance over SSHPlanned

A text menu for the same tasks when this page cannot be reached. That maintenance menu does not exist (roadmap C04).

Speak through the devicePlanned

Ask the assistant something and hear the answer from this page. The voice assistant runs as its own service and this page has no channel to it (roadmap V01, V03).
